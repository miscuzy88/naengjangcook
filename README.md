## v0.1에 들어간 것
- 재료 8개 종류(채소·과일, 고기, 해산물, 달걀·유제품, 두부·김치, 밥·면·빵, 소스·양념, 가루·기타)로 넣기·보기, 냉장/냉동/실온 재료와 소스·양념 32종 기록, 요리별 필요한 양념 표시, 재료별 기본 유통기한 자동 제안, 기한 임박 표시
- 보유 재료 기반 요리 60종 추천(한식·일식·중식·양식·분식·동남아, 종류별 필터) (기한 임박 재료 우선), 유튜브 검색 링크
- 부족 재료 장보기 목록, 쿠팡·네이버쇼핑(산지직송 검색) 링크
- 데이터는 각 휴대폰 브라우저에만 저장
